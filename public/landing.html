WebMCP Inspector

Inspect, test and improve WebMCP tools on any page

Open any page and see every tool it declares through WebMCP, whether from script or from forms. Run the tools, let a model use them, check with evals that it picks the right one, score how ready the page is for agents, see exactly what an agent receives over MCP, and hand the live page to Claude, Codex, Cursor or Zed in one click. Nothing to install.

Open Inspector

Open any page

Enter a URL. It opens in a live Webfuse session next to the inspector, with WebMCP available to the page.

Inspect and fix

See every tool, run it, check its score, and add or fix tools right in the live page.

Hand it to your agent

Send one prompt to your agent. It connects to the same page over MCP and uses its tools while you watch.

Discover

Every tool the page declares

Kept up to date as the page adds and removes tools.

Script tools JS API

Tools from document.modelContext.registerTool() with title, annotations, input and output schemas. Tools on the old navigator.modelContext are flagged.

Form tools HTML

Forms with toolname and tooldescription, with the schema the browser derives, plus every other form that could become a tool.

Live lifecycle

Registrations, removals by AbortSignal, toolactivated and toolcancel, and forms an agent submits with respondWith().

Test

Run the tools, and let models run them

Calls run in the real page, so you see what an agent would get.

Run tools

Arguments built from the schema, a JSON mode and example values. Inputs and results are checked against the schemas. Cancel, set a timeout, replay and diff calls.

Prompt debugger Models

Ask in plain words and watch Gemini Nano on your device, Claude, OpenAI or Gemini pick and call the page's tools, with your own key. Tools marked consequential ask you first.

Evals Tests

Write requests with the tool and arguments a model should choose, run them in one go, and see which pass. Rerun after changing a description, or compare models. Import and export as JSON.

Injection test

Append hostile text to every tool result, as a malicious review would arrive, and see whether the model starts calling tools you never asked for.

Improve

Make the page ready for agents

Find what confuses agents, fix it in place, and take the fix back to the site.

WebMCP score

An A–F grade from 35 checks: names, descriptions, schemas, safety hints, invisible characters, instruction-like text and forms. Copy the report or a badge.

Agent view

Each tool as the page registered it, next to the copy an agent receives over MCP, with what was added, changed or dropped on the way.

Build and export

Turn any form into a tool or write a script tool in the live page. Export the markup, a registerTool() snippet, or a Webfuse extension.
